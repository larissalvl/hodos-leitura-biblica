# Hodos — Bible Reading App

Android app for tracking Bible reading plans, built with MIT App Inventor (appinventor.mit.edu).

## About the project

The app (internal name Hodos) helps the user follow Bible reading plans, track progress, and configure preferences. The main screens are Screen1 (home screen), Hodos (main screen), Planos (reading plan selection, with the monthly plans in CSV format inside assets/), Progresso (reading progress tracking), and Configuracoes (user preferences).

## Repository structure

The file projeto_leitura_biblica.aia is the project's source file and should be imported into App Inventor. It is App Inventor's native format and is the project's source of truth (it is a binary zip, so its contents cannot be read directly on GitHub).

## Opening and editing the project

Go to ai2.appinventor.mit.edu and sign in with your Google account. In the projects panel, go to Projects, then Import project (.aia) from my computer, select the projeto_leitura_biblica.aia file from this repository, and the project opens normally with all screens, blocks, and assets.

## Updating the repository after editing in App Inventor

After making changes to the project in App Inventor, go to Projects, then Export selected project (.aia) to my computer, and replace the projeto_leitura_biblica.aia file in this repository with the new one, using Add file and Upload files on GitHub, then commit the changes.

## Technologies

MIT App Inventor (appinventor.mit.edu) — visual, block-based development for Android.
