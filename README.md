# Hodos — App de Leitura Bíblica

Aplicativo Android para acompanhamento de planos de leitura biblica, desenvolvido no MIT App Inventor (appinventor.mit.edu).

## Sobre o projeto

O app (nome interno Hodos) ajuda o usuario a seguir planos de leitura da Biblia, acompanhar o progresso e configurar preferencias. As telas principais sao Screen1 (tela inicial), Hodos (tela principal), Planos (selecao de planos de leitura, com os planos mensais em CSV dentro de assets/), Progresso (acompanhamento do progresso de leitura) e Configuracoes (preferencias do usuario).

## Estrutura do repositorio

O arquivo projeto_leitura_biblica.aia e o arquivo-fonte do projeto e deve ser importado no App Inventor. Ele e o formato nativo do App Inventor e e a fonte de verdade do projeto (e um zip binario, entao nao da para ler o conteudo direto pelo GitHub).

## Como abrir e editar o projeto

Acesse ai2.appinventor.mit.edu e faca login com sua conta Google. No painel de projetos, va em Projects e depois Import project (.aia) from my computer, selecione o arquivo projeto_leitura_biblica.aia deste repositorio, e o projeto abre normalmente com todas as telas, blocos e assets.

## Atualizando o repositorio apos editar no App Inventor

Depois de alterar o projeto no App Inventor, va em Projects e depois Export selected project (.aia) to my computer, e substitua o arquivo projeto_leitura_biblica.aia deste repositorio pelo novo, usando Add file e Upload files no GitHub, e faca o commit das alteracoes.

## Tecnologias

MIT App Inventor (appinventor.mit.edu) — desenvolvimento visual em blocos para Android.
